# Course books: notes for the native-teacher review

Points the writers flagged while drafting (docs/BOOKS.md). Each needs a decision from the reviewing teacher; delete a line once it is settled.

## English A2
- u1 p2, u4 p4: some "tap the words" targets are two-word phrases (am walking, more expensive), shown as one button.
- u2 p1: the -ed sounds use the plain labels t, d, id instead of phonetic symbols.
- u3 p1: "I’d like ___ orange juice" accepts *an* and *some*; the test gap "a ___ of milk" accepts carton, bottle, glass, jug.
- u3: *fruit* is treated as uncountable.
- u4 p2: *farther* is accepted next to *further*, though the table shows only *further*.

- u6 p4, u7 p4: invented usernames and place names (Ashby Vale and others).
- u7 p4: the reading uses non-defining relative clauses, which the lesson does not teach yet.
- u7 p1: one gap accepts *whom*; keep it at B1?
- u7 p3: customs (kissing on both cheeks, paying in cash, tipping) are deliberately not tied to a country.
- u8 p1: a future gap accepts *is starting*, *is going to start*, *starts*; check the list and the explanation.
