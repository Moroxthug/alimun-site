# Tutor part 7: the live call on the Privacy page and in the Terms (draft, waiting for the owner)

The live call (part 7) streams the student's voice to Google's Gemini API, with the instructions the server builds (level, language, a short summary of their learning, the latest class notes). The Privacy page and Terms are owner-locked blocks (`site/src/blocks/legal/gdpr.html`, `terms.html`, their translations in `site/src/blocks/legal/i18n/<lang>/`, hashes in `site/locked.json`), so nothing below is published yet. Until it is, only admins can call (`app_settings` `tutor_live` = `admins`). When the owner says yes: the Privacy sentence goes right after the tutor paragraph's sentence on Microsoft Azure; the Terms sentence replaces the tutor paragraph's sentence on recordings; the two hashes are re-approved; `npm run build:site` is run; then `tutor_live` is set to `all`.
